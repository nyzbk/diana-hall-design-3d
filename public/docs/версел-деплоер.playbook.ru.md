# Плейбук релиз-инженера Vercel & GitHub (site10k-vercel-deployer)

## 1. Продукт и Стандарты Доставки
- **Продукт:** Боевой задеплоенный 3D-сайт премиального уровня ($10,000 ценность).
- **Среда развертывания:** Vercel Global Edge Network.
- **Репозиторий:** GitHub (`https://github.com/nyzbk/{project}`).
- **Стандарт доступности:** 99.99% аптайм, SSL-сертификат, мгновенный Time to First Byte (TTFB < 100ms) через Vercel Edge.

## 2. Методы из 200 фреймворков и мировых образцов
- **Фреймворк #24 (Albert Olgaard — Production Atomic Rollouts):**
  - Атомарный деплой: новая версия становится активной только после успешного завершения сборки бандла и прогрева CDN.
- **Фреймворк #26 (Nate Herk — SPA Routing & No-404 Vercel Config):**
  - Настройка `vercel.json` с rewrites на `/index.html` для исключения 404-ошибок при обновлении страницы клиентом:
    ```json
    {
      "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
    }
    ```

## 3. Настроенные инструменты, MCP и Скиллы
- **Скиллы:**
  - `agency-devops-automator`: оркестрация деплоя и сборки.
  - `agency-git-workflow-master`: строгие конвенциональные коммиты (`feat:`, `fix:`).
  - `agency-platform-engineer`: управление конфигурацией edge-хостинга.
- **Инструменты командной строки:**
  - `git`, `gh`, `vercel`, `curl`.
- **Запреты:**
  - Запрещено коммитить временные файлы (`.DS_Store`, `node_modules`, `.env.local`).
  - Запрещено деплоить, если не пройдены тесты ревизора чистоты.

## 4. Пайплайн публикации и валидации
1. Проверка чистоты рабочей директории Git:
   ```bash
   git status --porcelain
   ```
2. Отправка в GitHub:
   ```bash
   git push origin master
   ```
3. Деплой в Vercel Production:
   ```bash
   npx vercel --prod --yes --token "$VERCEL_TOKEN"
   ```
4. Контрольная проверка доступности:
   ```bash
   curl -s -o /dev/null -w "%{http_code}" https://diana-hall-design-3d.vercel.app
   ```
   *Ожидаемый ответ:* `200`.
5. Уведомление владельца конторы о готовности релиза.
