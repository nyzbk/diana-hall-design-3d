# Плейбук склейщика мастер-видео (site10k-video-stitcher)

## 1. Продукт и Стандарты Мастер-Тура
- **Продукт:** Единый непрерывный видеофайл архитектурного тура `master_spatial_tour.mp4` для сайта за $10,000.
- **Главный критерий качества:** Нулевой шов. Зритель не должен чувствовать границ между сценами — ощущение должно быть таким, словно непрерывная 4K-камера на прецизионном слайдере мягко проплыла через всю резиденцию.
- **Стандарты кодирования:**
  - Контейнер: MP4 (H.264 / AVC).
  - Разрешение: 1920×1080 (Retina).
  - Частота кадров: строго 20.00 fps constant frame rate (CFR).
  - Длина: ровно 180 кадров (9.00 сек).
  - Качество: CRF 14 (фактически визуально без потерь).

## 2. Методы из 200 фреймворков и мировых образцов
- **Фреймворк #24 (Albert Olgaard — Concat Demuxer Integrity):**
  - Применение демоксера без перекодирования (stream copy), если входные клипы уже закодированы с идентичными параметрами матрицы квантования и GOP.
  - Исключение рассинхронизации PTS/DTS (Presentation / Decoding Time Stamps).
- **Фреймворк #25 (Creativo VR — Master Video Verification):**
  - Проверка первых и последних кадров каждого сочленения.
  - Точный тайминг: 3 секунды на экстерьер ──► 3 секунды на галерею/фойе ──► 3 секунды на главный зал и панораму океана.

## 3. Настроенные инструменты, MCP и Скиллы
- **Скиллы:**
  - `agency-video-streaming-engineer`: глубокая диагностика видеопотоков.
  - `agency-devops-automator`: автоматизация сборочных скриптов.
- **Инструменты командной строки:**
  - `ffmpeg`, `ffprobe`.
  - Скрипт сборки: `scripts/build_real_motion_tour.cjs`.
- **Запреты:** Не сжимать в zip, не нарезать в JPEG, не менять разметку сайта.

## 4. Пайплайн склейки и верификации
1. Вход: 3 файла в `assets/clips/`.
2. Команда сборки:
   ```bash
   ffmpeg -y -f concat -safe 0 -i clips.txt -c copy assets/master_spatial_tour.mp4
   ```
3. Валидация через ffprobe:
   ```bash
   ffprobe -v error -select_streams v:0 -show_entries stream=nb_frames,duration,width,height -of default=noprint_wrappers=1 assets/master_spatial_tour.mp4
   ```
   *Ожидаемый результат:* `nb_frames=180`, `duration=9.000000`, `width=1920`, `height=1080`.
4. Передача эстафеты нарезчику кадров `site10k-frame-slicer`.
