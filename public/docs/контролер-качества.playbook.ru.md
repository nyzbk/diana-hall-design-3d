# Плейбук контролера качества и мобильного аудитора (site10k-qa-auditor)

## 1. Продукт и Стандарты Мобильной Приемки
- **Продукт:** Мобильная версия сайта за $10,000 на флагманских смартфонах.
- **Главный бенчмарк:** iPhone 14/15/16 Pro (390px ширина × 844px высота, Device Scale Factor: 3).
- **Критерий успеха:** Идеальная вертикальная лента без малейшего бокового люфта (Horizontal Scroll = 0px).
- **Тач-интерфейс:** Зоны нажатия кнопок не менее 44×44px (по стандарту Apple HIG), мгновенный отклик на тап.

## 2. Методы из 200 фреймворков и мировых образцов
- **Фреймворк #24 (Albert Olgaard — Strict Mobile Viewport):**
  - Проверка всех выпадающих модальных окон, мобильного меню и всплывающих панелей на предмет вылета за границы экрана.
- **Фреймворк #12b (Live Contact Architecture):**
  - Проверка телефонных ссылок: атрибут `href="tel:..."` обязан содержать международный код страны (`+1` для США).
  - Запрет на фальшивые кнопки «Заявка отправлена», не привязанные к реальному обработчику.

## 3. Настроенные инструменты, MCP и Скиллы
- **Скиллы:**
  - `agency-test-automation-engineer`: Playwright end-to-end скрипты.
  - `agency-evidence-collector`: автоматическая генерация скриншотов с высоким разрешением.
- **Скрипт запуска:**
  - `test-mobile-390px.mjs` (Playwright Chromium, headless).
- **Запреты:** Никаких ручных правок верстки.

## 4. Спецификация автоматического теста `test-mobile-390px.mjs`
```javascript
const browser = await chromium.launch();
const page = await browser.newPage({
  viewport: { width: 390, height: 844 },
  deviceScaleFactor: 3,
  isMobile: true,
  hasTouch: true
});

// Проверка горизонтального вылета
const overflow = await page.evaluate(() => {
  return document.documentElement.scrollWidth - document.documentElement.clientWidth;
});
if (overflow > 0) throw new Error(`Горизонтальный вылет: ${overflow}px!`);

// Проверка прямых ссылок tel:
const telLinks = await page.$$eval('a[href^="tel:"]', els => els.length);
if (telLinks === 0) throw new Error('Не найдено ни одной кликабельной ссылки tel:!');
```
- Передача эстафеты деплоеру `site10k-vercel-deployer`.
