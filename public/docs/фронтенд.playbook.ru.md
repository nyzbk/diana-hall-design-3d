# Плейбук ведущего фронтенд-инженера (site10k-frontend-engineer)

## 1. Продукт и Стандарты Интерфейса
- **Продукт:** Премиальный веб-интерфейс за $10,000 с интерактивным пространственным обходом.
- **Главный экран (Hero Section №1):**
  - Занимает 100% экрана пользователя (`100vw × 100vh`).
  - Высота скролл-трека: ровно `450vh`.
  - Позиционирование: `sticky top-0 h-screen w-full`.
  - Управление пальцем на смартфонах и колесом мыши на десктопах.

## 2. Методы из 200 фреймворков и мировых образцов
- **Фреймворк #24 (Albert Olgaard — Native Touch Scrubber):**
  - Отсутствие промежуточных анимаций-заглушек или видео-плееров на мобильных устройствах.
  - Прямой маппинг движения пальца на номер кадра через слушатель скролла и `requestAnimationFrame`.
- **Фреймворк #27 (Sourany — CSS Clip Law):**
  - Замена устаревшего `overflow-x: hidden` на стандартизированный W3C `overflow-x: clip;`.
  - В браузерах Safari (iOS) и Brave/Chrome свойство `overflow: hidden` создает новый контекст форматирования прокрутки (Scroll Container), что намертво блокирует работу `position: sticky`. `overflow-x: clip;` обрезает горизонтальные вылеты, сохраняя вертикальный sticky-контекст документа нетронутым.
- **DPR Scaling Canvas Engine:**
  - Отрисовка на Canvas с учетом плотности пикселей экрана:
    ```typescript
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    canvas.width = rect.width * dpr;
    canvas.height = rect.height * dpr;
    ctx.scale(dpr, dpr);
    ctx.imageSmoothingEnabled = true;
    ctx.imageSmoothingQuality = 'high';
    ```

## 3. Настроенные инструменты, MCP и Скиллы
- **Скиллы:**
  - `agency-frontend-developer`: глубокая оптимизация React-компонентов.
  - `agency-ux-architect`: дизайн-системы и адаптивная сетка.
  - `agency-performance-benchmarker`: контроль 60 FPS рендеринга.
- **Стек:** React 19, TypeScript 5, Vite 6, Tailwind CSS 3, Lucide-React.
- **Запреты:**
  - Запрещено использовать кнопки Play/Pause, таймлайн-ползунки или плееры поверх Hero-тура.
  - Запрещено размещать тур в Секции №2 или футере.
  - Запрещено выводить технические названия («Three.js», «180 frames», «WebGL»).

## 4. Пайплайн сборки и самоконтроля
1. Сборка проекта:
   ```bash
   npm run build
   ```
2. Контроль размера бандла: общий вес JS gzip не должен превышать 120 КБ.
3. Проверка кэш-бастинга: все пути к кадрам обязаны содержать `?v=...`.
4. Передача эстафеты ревизору чистоты `site10k-cro-inspector`.
