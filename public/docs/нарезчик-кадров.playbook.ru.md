# Плейбук нарезчика 180 кадров и упаковщика ZIP (site10k-frame-slicer)

## 1. Продукт и Стандарты Покадровой Секвенции
- **Продукт:** Последовательность кадров для ультраплавного скролла Apple-уровня сайта за $10,000.
- **Точное число кадров:** ровно 180 кадров (`frame_0001.jpg` .. `frame_0180.jpg`).
- **Разрешение каждого кадра:** 1920×1080 (Full HD Retina).
- **Сжатие:** JPEG с качеством `qscale:v 2` (сохранение микроконтраста мрамора и дерева без цветового размытия).
- **Упаковка:** Обязательный архив `public/frames.zip` для резервного скачивания и мгновенного кэширования.

## 2. Методы из 200 фреймворков и мировых образцов
- **Фреймворк #24 (Albert Olgaard — Frame Scrubber Precision):**
  - Непрерывность нумерации с ведущими нулями (`%04d`).
  - Проверка веса каждого кадра (в среднем 300–450 КБ на кадр при Retina-качестве).
- **Фреймворк #25 (Creativo VR — Canvas Asset Delivery):**
  - Подготовка заголовков для CDN-кэширования.
  - Поддержка быстрого прогрессивного считывания первого чанка изображения браузером на смартфонах.

## 3. Настроенные инструменты, MCP и Скиллы
- **Скиллы:**
  - `agency-video-streaming-engineer`: прецизионная покадровая экстракция.
  - `agency-performance-benchmarker`: мониторинг времени декодирования и веса ассетов.
- **Инструменты командной строки:**
  - `ffmpeg`, `zip`, `unzip`.
- **Запреты:** Не изменять логику `Hero.tsx`, не менять тексты на сайте, не удалять мастер-видео.

## 4. Скрипт сборки и верификация
```bash
# Очистка и нарезка 180 кадров
rm -rf public/frames && mkdir -p public/frames
ffmpeg -y -i assets/master_spatial_tour.mp4 -qscale:v 2 public/frames/frame_%04d.jpg

# Проверка количества
COUNT=$(ls -1 public/frames/frame_*.jpg | wc -l)
if [ "$COUNT" -ne 180 ]; then
  echo "ОШИБКА: создано $COUNT кадров вместо 180!"
  exit 1
fi

# Упаковка в ZIP
zip -j -q public/frames.zip public/frames/frame_*.jpg
```
- Передача эстафеты фронтенд-инженеру `site10k-frontend-engineer`.
