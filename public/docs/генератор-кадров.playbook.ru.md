# Плейбук генератора 4K мастер-кадров (site10k-image-generator)

## 1. Продукт и Стандарты Визуального Качества
- **Продукт:** Кинематографичный 3D-тур премиального сайта за $10,000.
- **Стандарт разрешения:** Честное 4K UHD (3840×2160 пикселей) при 72–300 DPI.
- **Цветовая субдискретизация:** 4:4:4 или 4:2:2, исключающая ступенчатые градиенты на темном люксовом фоне (`#0B0B0B`).
- **Сенсорный фокус:** Натуральные материалы высшего качества: итальянский мрамор Calacatta Gold, полированная бронза, мореный дуб, архитектурное стекло, закатное солнце Флориды.

## 2. Методы из 200 фреймворков и мировых бенчмарков
- **Фреймворк #25 (Creativo VR — Studio Stills Workflow):**
  - Подбор реального архитектурного контекста (Naples, Port Royal, Palm Beach).
  - Генерация в 16:9 без водяных знаков и текста.
  - Постобработка: расширение краев (outpainting) для идеального покрытия всего viewport на любых мониторах (Retina 5K, 4K, Pro Display XDR).
- **Фреймворк #13 (Viktor Oddy — Google AI Studio Imagen 3 Process):**
  - Использование негативных промптов: `ugly, distorted, blurry, grain, lowres, text, watermark, cartoon, oversaturated, artifact, duplicate furniture`.
  - Моделирование естественной кинематографичной оптики: 35mm lens, f/2.8 aperture, natural volumetric architectural lighting, subtle golden hour ambient.
- **Фреймворк #20 (Jack Roberts — Exploded Spatial Sequence):**
  - Непрерывная траектория: каждый следующий ракурс является логическим продолжением предыдущего (пролет вперед без резких скачков направления на 180 градусов).

## 3. Настроенные инструменты, MCP и Скиллы
- **Скиллы:**
  - `agency-ai-engineer`: интеграция нейросетевых пайплайнов генерации.
  - `agency-image-prompt-engineer`: филигранная инженерия промптов для фотореализма.
  - `agency-inclusive-visuals-specialist`: эстетическая выверенность и отсутствие стереотипов.
- **MCP и скрипты:**
  - Google AI Studio API: `imagen-3.0-generate-002`.
  - xAI Grok API: `grok-2-image` (Aurora engine).
  - Скрипт постобработки: Sharp Lanczos3 (`scripts/upscale_keyframes_4k.mjs`).
- **Запреты:** Никакой генерации видео, никакой склейки клипов, никаких изменений в файлах фронтенда.

## 4. Пайплайн обработки и файлы
1. Генерация сырых ключевых кадров: `assets/keyframes/raw_01.png` .. `raw_04.png`.
2. Обработка и апскейл скриптом:
   ```bash
   node -e "
     const sharp = require('sharp');
     // Lanczos3 kernel, 3840x2160, quality 95
   "
   ```
3. Сохранение итоговых мастер-кадров:
   - `assets/keyframes/keyframe_01_4k.jpg` (Фасад / Вход)
   - `assets/keyframes/keyframe_02_4k.jpg` (Фойе / Галерея)
   - `assets/keyframes/keyframe_03_4k.jpg` (Главный салон)
   - `assets/keyframes/keyframe_04_4k.jpg` (Терраса с бассейном)
4. Проверка веса и четкости: размер каждого файла от 1.5 МБ до 4.5 МБ в 4K.
5. Передача эстафеты аниматору переходов `site10k-clip-animator`.
